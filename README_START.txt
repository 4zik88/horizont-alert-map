ЗАПУСК КАРТЫ

WINDOWS
1. Распакуйте архив в отдельную папку.
2. Запустите START_MAP.bat.
3. Не закрывайте чёрное окно сервера, пока используете карту.

macOS
1. Распакуйте архив в отдельную папку.
2. Дважды кликните START_MAP.command — откроется Терминал и запустится сервер.
   Браузер откроется автоматически на http://127.0.0.1:8765/
3. Не закрывайте окно Терминала, пока используете карту. Остановить: Ctrl+C.

Если macOS не даёт запустить файл:
- «файл не является исполняемым» — откройте Терминал в папке карты и выполните:
      chmod +x START_MAP.command
- Gatekeeper («неизвестный разработчик») — правый клик по файлу > «Открыть»,
  затем подтвердите «Открыть» в диалоге. Достаточно сделать один раз.
- «Python 3 не найден» — установите Python:  brew install python
  или скачайте с https://www.python.org/downloads/macos/

Альтернатива для macOS/Linux — запуск из Терминала:
      cd /путь/к/папке && python3 server.py
