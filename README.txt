ГОРИЗОНТ — радарна карта України

Запуск:
1. Распакуйте архив.
2. Откройте index.html через Live Server в Visual Studio Code.
3. Для загрузки карты требуется интернет.

Изменения:
- янтарная радарная тема;
- добавлена детальная серая карта OpenStreetMap;
- при сильном приближении видны дома, улицы, поля и другие объекты;
- подписи населённых пунктов в Украине отображаются на украинском по данным OpenStreetMap;
- названия областей принудительно переведены на украинский язык.

ГРАНИЦЫ ОБЛАСТЕЙ
Карта загружает 25 отдельных контуров областей, объединяет их в один слой
и сохраняет в локальном кеше браузера. После первой успешной загрузки слой
не зависит от повторной доступности источника.

NEPTUN alerts integration:
- Active alert oblasts are highlighted in red.
- Realtime updates use the NEPTUN WebSocket/SDK.
- If the SDK is unavailable, REST fallback runs once every 7 seconds (about 8–9 requests/minute).
- Visible NEPTUN attribution is included as required.

Виправлення v8:
- REST /api/v1/alerts тепер запускається завжди, навіть коли SDK NEPTUN завантажився.
- Це усуває ситуацію, коли SDK передавав загрози, але не передавав список тривог.
- Частота REST: один запит кожні 7 секунд (приблизно 8–9 разів на хвилину).
- Червону заливку активної області зроблено помітнішою.
